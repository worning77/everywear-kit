# EveryweAR expert session kit

Screen-share surface for the EveryweAR expert-review sessions (IRB STU00226775, exempt).

- Session page: open `index.html` (or the GitHub Pages URL). Step-by-step, participant-facing.
- Facilitator layer: press `F`, or open the page with `#fac` appended in a second (private) window.
- Responses live in the interviewer's own browser (localStorage) and are exported as one JSON at the Wrap-up step. Interviewers can run sessions independently; export after every session and clear before the next.

Master copy of this page lives in the paper repo (`everyweAR-CHI/Docs/expert_review_kit.html`); edit there, then copy here and push.
